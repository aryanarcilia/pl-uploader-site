PL Uploader

PL Uploader is a personal tool that uploads videos to the operator's own YouTube channel. It reads a video file and its metadata (title, description, tags, scheduled publish time) from a local folder and uploads it using the YouTube Data API.

The tool is used only by its owner and is not offered as a public service.

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
